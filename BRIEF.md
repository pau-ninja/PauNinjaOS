# PauNinjaOS build brief

Create a minimal, reproducible Apple Silicon operating-system distribution with PauNinjaOS branding. Reuse the supported Apple Silicon boot chain and a declarative Linux base. Provide a safe macOS bootstrap, release-image metadata, remote update workflow, and an initially console-only system ready for a custom visual shell.

The first release targets only Apple Silicon models covered by the pinned installer firmware set. M3 and newer Macs are excluded until the upstream stack and real hardware tests support them.

Upstream licenses and attribution must remain intact. Upstream project names may appear in developer documentation and source references, but not as the user-facing product name.
